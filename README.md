# Design review agent

Automatically check your web application for design, UX, and accessibility issues

Ways to use it:

- [GitHub Action](github-action/README.md) - Run inside a Github action
- [Agent skill](skill/README.md) - Install as a skill in your code harness
- [CLI](cli/README.md) - Run from the command line

See [DEVELOPERS.md](DEVELOPERS.md) for development setup, architecture, and validation.
